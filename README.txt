EcoSort - Interactive Waste Segregation Simulator
Computer Graphics Lab mini project (Python + Pygame, 2D)

1. Install Python from python.org (tick "Add python.exe to PATH")
2. Open this folder in VS Code, open the terminal and run:
       pip install pygame
3. Run the game:
       python main.py

Controls: Left/Right arrows or A/D to walk, mouse to click menus,
Esc = back to places menu, F1 = shows the Computer Graphics concepts used on the current screen.
